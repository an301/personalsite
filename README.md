# personalsite

Anish Nambirajan's personal site. Plain HTML, CSS, and one script, with no build step.

- `index.html`: content
- `styles.css`: layout and type (Corinthia for display, Hanken Grotesk for text)
- `koala.js`: the pixel court in the hero, drawn on a canvas

Run it locally with any static server, for example `python3 -m http.server`, then open http://localhost:8000.

To deploy on GitHub Pages, set Pages to serve the `main` branch from the root.
